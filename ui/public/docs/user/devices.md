# Devices

The **Devices** page is your command center with overview for managing all WLED units.

## Key Actions

- **Add Device**: Manually add a device by IP address if it wasn't automatically discovered.
- **View Details**: Click on a device card to see detailed status, controls, and configuration.
- **Delete**: Remove a device from your managed list.

## Refresh

The **Refresh** button updates the status of all your devices by querying them directly over the network. Use this to:

- Get the latest online/offline status for all devices.
- Update device information such as brightness, power state, and signal strength.
- Verify connectivity after network changes.

> [!TIP]
> On the **Device Details** page, there's also a dedicated refresh button (🔄) in the header that refreshes only that specific device's information.

## Device Details

Clicking on a device card opens the **[Device Details](#/docs/user/device-details)** page.
