# WLED Manager Documentation

Welcome to the WLED Manager user documentation. Use the navigation menu to learn more about the features and capabilities of the application.

## Getting Started

WLED Manager is designed to help you discover, manage, and configure your WLED devices from a central dashboard.

> [!IMPORTANT]
> After first installation, automated processes (schedulers) require a **manual first run**. Navigate to [Schedulers](#/docs/user/schedulers) and click "Run Now" on each scheduler to initialize them before they will run automatically.

### Key Features

- [**Network Scan**](#/docs/user/network-scan): Discovery tool to find devices on your network. This should be the first step after installation.
- [**Device Adoption**](#/docs/user/adoption): Adopt discovered devices to manage them.
- [**Devices**](#/docs/user/devices): Detailed management of connected WLED devices.
- [**Backups**](#/docs/user/backups): Backup and restore functionalities for device configurations.
- [**Compare Backups**](#/docs/user/compare-backups): Compare differences between backup versions.
- [**Compare Configs**](#/docs/user/compare-configs): Compare configuration differences between devices.
- [**Schedulers**](#/docs/user/schedulers): Automate device actions.
- [**Secrets**](#/docs/user/secrets): Manage sensitive information securely.
- [**App Config**](#/docs/user/app-config): Configure application settings, including network tuning and email notifications.
- [**Dashboard**](#/docs/user/dashboard): Overview of your network and device status.

## Quick Start

1. Run a [Network Scan](#/docs/user/network-scan) to discover your WLED devices.
2. Review discovered devices on the [Devices](#/docs/user/devices) page.
3. Configure [Schedulers](#/docs/user/schedulers) and run them manually for the first time.
4. Set up [Backups](#/docs/user/backups) to protect your device configurations.
