# Dashboard

The **Dashboard** provides a high-level overview of your WLED ecosystem.

## Overview Features

- **Device Status**: Quickly see how many devices are online or offline.
- **System Health**: Monitor the status of the WLED Manager services.

## Quick Actions

Perform common tasks directly from the dashboard header:

- **Trigger Backup Email**: Sends an email containing download links for all devices. Useful for having device links stored outside your infrastructure—for example, if your server crashes and you need to access your devices. Requires [email settings](#/docs/user/app-config) to be configured.
- **Adopt/Release**: If unmanaged devices are detected, you can [adopt](#/docs/user/adoption) them directly from the recent devices list.

## Using the Dashboard

1. **View Summary**: Check the summary cards for immediate insights.
2. **Recent Activity**: View detailed logs or recent events.
