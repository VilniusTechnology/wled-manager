# Compare Backups

**Compare Backups** allows you to inspect the differences between two specific backup files.

## Usage

1. Select **Source Backup** (the original or older version).
2. Select **Target Backup** (the new or modified version).
3. **Compare**: The tool highlights added, removed, or modified keys and values.

This is useful for troubleshooting what changed between two points in time or for comparing one device's configuration with another.
